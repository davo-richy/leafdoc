How accurate is LeafDoc?

A photo is not a laboratory test. This page says exactly what we have measured, and what we have not.

Not yet measured

The labelled test set has not been run, so LeafDoc has no accuracy figure to publish.

What we will report

A top-1 score on 30–50 labelled PlantVillage images: the share of photos where one of the first two candidate problems matches the true disease, plus a separate score for healthy plants.

How the test runs

  1. Put 30–50 labelled images in test/images/, named like Tomato___Late_blight__01.jpg.
  2. Run the harness against the same model the app uses.
  3. Review every row by hand: the automatic match is keyword-based and deliberately loose.
GEMINI_API_KEY=your_key node test/run-eval.mjs

The harness writes test/accuracy-results.md. Until that file has a table, this page keeps saying “Not yet measured”.

Why the number will not be 100%

  • Lab images are cleaner than a phone photo taken in a field.
  • Several diseases share symptoms, and nutrient problems can look like disease.
  • The model is asked to be honest about uncertainty, so it sometimes asks for another photo instead of guessing.

That is why every result shows a confidence figure, a “not sure yet” state, and a reminder to ask a local extension officer for serious problems.

Check it yourself

Every scan is a test: photograph the same plant again after a week and compare. LeafDoc keeps past scans on your device so you can see whether advice helped.
